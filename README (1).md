# 📝 Lista de Tarefas

Aplicativo de tarefas feito com **HTML, CSS e JavaScript puro** — sem frameworks e sem dependências.

## Funcionalidades

- Adicionar tarefas (botão **+** ou tecla `Enter`)
- Marcar como concluída
- **Editar** com duplo clique (`Enter` salva, `Esc` cancela)
- Apagar tarefas
- Filtros: **Todas**, **Pendentes** e **Concluídas**
- Contador de tarefas pendentes
- Botão para limpar todas as concluídas
- As tarefas ficam **salvas no navegador** (`localStorage`), mesmo depois de fechar a página
- Layout responsivo (funciona no celular)

## Como usar

```bash
git clone https://github.com/SEU-USUARIO/lista-de-tarefas.git
cd lista-de-tarefas
```

Depois é só abrir o `index.html` no navegador.

## Publicar no GitHub Pages

1. Vá em **Settings → Pages**
2. Em **Source**, escolha **Deploy from a branch**
3. Selecione a branch `main` e a pasta `/ (root)`
4. Salve — o site ficará em `https://SEU-USUARIO.github.io/lista-de-tarefas/`
